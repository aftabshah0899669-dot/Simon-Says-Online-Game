# Simon Says Game

A browser-based Simon Says memory game built using HTML, CSS, and JavaScript.  
The game challenges players to remember and repeat an increasing sequence of colors.

## Features
- Random color sequence generation
- Level-based difficulty increase
- Interactive button animations
- Game over detection and restart functionality

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Press any key to start the game.
2. Watch the color that lights up.
3. Click the same color.
4. Repeat the sequence correctly to move to the next level.
5. The sequence becomes longer each level.
